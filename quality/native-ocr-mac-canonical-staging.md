# Mac canonical staging diagnostic

The independently converted Mac graph is equivalent to the pinned Windows graph but two serialized parameter files have different names / Split aliases. This isolated experiment shares only generated names, whitespace and alias choices, not raw parameter files, op attributes, model weights, native executables or tarballs. Mac reconstructs the parameter files locally from its own pinned conversion, then demands the pre-existing exact Windows hashes and graph fingerprints. All production integrity pins and the empty approved download catalog are unchanged. If staging succeeds, evidence JSON is retained; no installation or release is claimed. The generated label recipe is build metadata derived from the pinned public Apache-licensed model inputs, with no binary data or raw parameter file.
