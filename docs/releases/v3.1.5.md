# v3.1.5 — Vision reliability and model routing / 视觉稳定性与模型路由

**Release candidate, not published / 候选版，尚未发布。** Publication requires a final main SHA, complete CI/security and real Host/Desktop gates, and the protected Release workflow with immutable tag, npm tarball identity, GitHub Release assets and OIDC provenance. / 正式发布需绑定最终 main SHA，完成安全与真实 Host 验收，并经过受保护 Release 工作流验证包体、附件和来源证明。

## Runtime fixes / 运行时修复

- **#798: responsive cancellation / 取消后及时结束。** Vision Chain, direct `vision-http` and DVR-owned transparent adapters now bound waits on noncooperative visual iterators and cap abort cleanup at 1 second. Empty/whitespace/JSON-null answers are no longer cached as valid recognition. / 识图流遇到不响应取消的后端时不再无限等待；空白或 JSON 空结果不再写入成功缓存。
- **#799: cancellation is not backend failure / 主动取消不触发后端熔断。** A user/Host abort no longer records a provider failure in the breaker or turn-scoped memory. Actual HTTP 550/503 and timeouts retain failure classification. / 主动停止不会污染本轮后端故障记忆，真实错误处理规则保持不变。
- **#800: fair fallback budgets / 备用模型保留超时预算。** For multiple visual backends, `vision_describe`, vision OCR and opt-in whole-turn remote Vision Chain give later candidates a bounded opportunity after an earlier model hangs. Slow single-provider success and text-only routing preserve existing timeouts. / 前一个识图模型卡住时仍可尝试后续健康模型，覆盖视觉 OCR 和整轮视觉路由，不无故缩短单模型与纯文本超时。
- **#801: injected composite model dispatch / 注入模型正确分发。** A model-picker composite visual entry matching a live configured routing pair is dispatched through the registered `vision-chain`, with image blocks preserved, rather than sent as a foreign model ID to `deepseek-official`. Ordinary DeepSeek mirror models remain unchanged. / 模型列表中的有效视觉复合模型走实际视觉链，普通 DeepSeek 模型仍使用原委托路径。

## Offline doctor / 离线诊断

- **#802 / issue #797: potential Host-core shadowing / Host 核心依赖覆盖风险。** A bounded, read-only scan reports profile-local `@deepseek-ai/dsh-*` manifests and third-party plugins declaring direct runtime Host-core dependencies. Findings are **possible/unverified**, not proof of actual Host module resolution. No automatic removal or profile mutation. Shareable reports contain only safe counts, not package paths or raw configuration. / 只读有界检查可疑核心包及第三方运行时依赖，仅作未验证风险提示，不自动修改用户文件；可分享报告只输出安全统计。

## Open user reports / 尚未确认的现场反馈

- **#791 remains open:** The original reporter's 550 → 503 source is unknown and their restored image recognition was achieved independently; the fixes above address separately reproduced bugs, not proven provenance of those errors. / 原用户 550、503 的供应商或 Host 来源尚不确定，不能声称本版已确认解决原始问题。
- **#792 remains open:** Windows Desktop raw JS/CSS display has no verified field root cause. The prior renderer regression gate and new doctor advisory do not prove it is fixed. / Windows Desktop 启动源码外露的现场根因未确认，不能将检测门禁或诊断告警当作已修复证据。
- No Settings migration, new runtime dependencies/providers, public API break, Node/DSH support floor rise, broader permissions, or change to the default cloud image-egress/privacy policy. / 不变更设置结构、运行时依赖、公共 API、最低支持窗口、权限和默认云端识图外发政策。

## Upgrade / 升级

**Only after verified publication**, update through the existing DSH profile plugin manager or an explicit `dsh-vision-router@3.1.5` install. Back up configuration before plugin changes; preserve all session data. / **仅在确认正式发布后**，通过原有插件管理器或指定版本升级，不需要删除配置或聊天历史。
