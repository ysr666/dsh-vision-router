# v3.1.3 — DSH RC1 dynamic visual routing compatibility / DSH RC1 动态视觉路由兼容修复

**Candidate release notes.** This document describes source changes proposed for release; publication is complete only after the protected workflow verifies the exact main commit, immutable tag, npm package identity, provenance and GitHub Release artifacts. / **候选版说明：** 本文描述待发布的源码变更；须经受保护工作流核验精确 main 提交、不可变标签、npm 包体一致性、来源证明和 GitHub Release 附件后，才能认定正式发版。

## DSH 0.2.2-rc.1 dynamic routing fix / RC1 动态路由修复

- **#786 (fixes #787):** Adapt optional whole-turn image routing to the RC1 Agent model-selection contract. DVR selects a model via the supported `agent.model.select()` before Agent pre-step freezes provider/model, tool admission and prompt assembly; the modern `agent/request` hook no longer rewrites the chosen model. Legacy Hosts without the native selector retain their previous route path. / **#786（修复 #787）：** 适配 RC1 的 Agent 预步骤模型选择契约，使用官方 `agent.model.select()` 在模型、工具和提示词固定前选择图片模型；新版 Host 不再在 `agent/request` 阶段强改模型。旧版 Host 保留原有分流路径。
- A subsequent text-only turn can restore the original text model when reverse routing is enabled, without overriding a different model manually selected by the user. Queue/steer, turn-stopping timing, missing adapters/projections, unloaded Agent state, offloaded images and failure handling have regression coverage. / 开启反向路由时，后续纯文本轮次可恢复用户原先的文字模型，且不覆盖用户手动改选的其他模型；排队、插话、轮次结束竞态、缺失适配器或投影、Agent 卸载及异常路径均有回归测试。
- The **default tool-only vision path remains the default** and gets its progressive vision tools mounted before the RC1 tool-admission snapshot; this release does not silently turn on whole-turn model switching. / **默认仍为工具识图模式**；渐进式识图工具会在 RC1 工具许可快照前注册，不会擅自开启整轮模型切换。

## Exact-source and real Host acceptance / 精确源码及真实 Host 验收

- The DSH 0.2.2-rc.1 release is pinned to immutable source commit `66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db`. Exact-source / Host Gate passed **6/6** on Linux, macOS and Windows, including real Chromium lifecycle, macOS Desktop, Windows Desktop Node 24.9 and 24.21. / DSH RC1 固定到上述不可变源码；六项门禁全部通过，涵盖三端、真实 Chromium、macOS Desktop、Windows Node 24.9/24.21 Desktop。
- The whole-turn Desktop E2E verified real HTTP delivery of an image to a distinct visual adapter, a subsequent text request to the original adapter, rendered answers, and accepted Session model-selection projection. Windows Node 24.9 independently validated the default tool-only image path. / 整轮分流 E2E 真实验证了视觉适配器收到图片、纯文本回合返回原文字适配器、界面可见回复和 Session 模型选择投影；Windows Node 24.9 另行验证默认工具识图流程。
- **Scope limits:** RC1 itself requires **Node >=24.9**; this does not raise DVR's declared Node support range on older Hosts. RC1's default model-switch compaction reserves 65,536 tokens, which cannot fit a 32K context-window destination. Such models may need explicit Host `compaction-basic.modelPolicies` headroom configuration, or can stay on the default tool-only mode. This exact RC1 validation does not promise blanket compatibility with future 0.2.x previews. / **范围限制：** RC1 自身要求 Node ≥24.9，但插件对旧 Host 的 Node 支持声明不变。RC1 的默认模型切换压缩预留 65,536 token，无法适配 32K 上下文目标；此类模型可能需要按模型设置 Host 的 `compaction-basic.modelPolicies`，或继续使用默认工具识图。当前验收仅针对固定 RC1，不代表未来 0.2.x 全部版本均已验证。
