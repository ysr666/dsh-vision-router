# v2.2.3

DSH Vision Router 2.2.3 is a focused stability and compatibility hotfix for the 2.2.x line, with exact verification for the current DSH stable channel and the 0.1.7-rc.2 next channel.

## Highlights

- Fixes the bundle HMR/recompose failure behind #547/#552. DVR now restores its inserted bundle row with an independent `disabled: false` overlay, so Loader disposal cannot persist a shared-object `disabled=true` mutation into the next composition.
- Qualifies DSH `0.1.7-rc.2` as exact next-channel verification evidence (#553), including Session format v4 replacement handling and the new `SettingsForms + ConfigEditor` settings seam. Unknown future Session formats remain fail-closed.
- Adds explicit local-model controls for reasoning effort and visible output budget (#526/#550), instead of hard-coding one Ollama behavior across local OpenAI-compatible backends.
- Improves vision/OCR resilience: configurable default OCR engine policy (#544), structured-answer failover when a backend returns malformed structured output (#548), and clearing stale chunk text when a long-OCR retry returns blank (#549).
- Repairs one-time Session event-feed activation gaps (#543) without returning production repair to eager full-history reads.
- Makes npm Trusted Publishing recovery idempotent (#542): delayed public-registry propagation is retried, exact immutable tarball identity is verified, mismatches/fatal responses fail closed, and an already-published exact tarball is not republished.
- Updates the Scorecard SARIF uploader to CodeQL Action v4.38.2 at an immutable commit SHA (#531).

## Compatibility

- Node 22 and Node 24 remain supported.
- Windows, macOS, and Linux remain gated.
- The public minimum DSH Host remains `0.1.0-rc.8`.
- Current stable evidence is DSH `0.1.5-rc.3`.
- Exact DSH `0.1.7-rc.2` coverage is next-channel verification evidence, not a promise that every future preview Host is supported.
- Existing 2.2.x settings require no migration.

## Validation

- Full Node 22/24 test suites pass on the merged fixes.
- Exact-source Windows/macOS/Linux gates pass for the supported/current compatibility window and DSH `0.1.7-rc.2`.
- Real Host + Chromium lifecycle coverage passes for stable and `0.1.7-rc.2`, including startup, Vision toggle, mixed attachments, Settings save/reload/readback, and live recomposition coverage.
- Dependency review, CodeQL, adversarial/fuzz, fetch-composition, native screenshot, and resource-boundary gates pass on the corresponding PRs.

## Upgrade

Users on DSH 0.1.7-rc.2, local Ollama/LM Studio-style backends, or workloads that exercise long OCR / repeated Host recomposition should upgrade to 2.2.3 after release. No settings migration is required.
