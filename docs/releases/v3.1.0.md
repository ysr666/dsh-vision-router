# v3.1.0 — release notes / 更新说明

These notes describe the v3.1.0 source changes. The published package and its provenance must be verified separately through the protected release workflow, GitHub Releases and npm.

本文描述 v3.1.0 源码改动。实际已发布的包体及来源证明需通过受保护流程、GitHub Releases 和 npm 另行核实。

## Simpler setup / 更容易使用

- **#754**: The Vision Router General page no longer treats merely choosing a model as proof that images can reach it. When DSH declares a model text-only, a concise bilingual explanation points to DSH Settings → Models → Image input, with a Recheck action and optional collapsed legacy Host help. The plugin never silently changes Host model metadata, and enabling a flag does not grant multimodal capabilities to a text-only model.
- **#754**：不再把“选中了模型”误报成“肯定能看图”。DSH 明确声明纯文本时，默认界面用简短中文/英文提示用户在 DSH「设置 → 模型」开启图片输入，并提供「重新检测」；旧版 YAML 字段折叠在可选帮助中。插件不会擅自修改 Host 模型配置，也不会把纯文本模型变为多模态模型。
- **#756**: Cloud-image privacy guidance now tells the user exactly how to stop **Vision Router image uploads**: on the DSH machine, enable Local-only vision in Vision Router → General and **Save**. A browser-local “Do not remind again” preference minimizes repeated explanation, while retaining a short egress status and a “How to stop uploads” control. Dismissing the notice **does not consent to uploads or change settings**. Unsaved changes never claim that the local-only policy has taken effect. A cloud chat model can still receive **derived vision-result text**; fully local use also requires selecting a local chat model.
- **#756**：清楚告诉用户在运行 DSH 的电脑上打开 Vision Router「常规」，开启「仅本地视觉」并**保存**，即可阻止**本插件向云端视觉服务上传图片**。可勾选「不再提醒」，该浏览器仍保留一行提醒和「查看如何关闭出网」入口；收起提醒**不等于授权上传，也不会修改配置**。未保存的草稿不会误报为已生效。如果聊天模型在云端，**识图结果文字仍可能出网**；完全本地使用还需在聊天页选择本地聊天模型。

## Compatibility, fixes and maintenance / 兼容与修复

- **#751**: Qualified DSH `0.2.1-rc.3` against exact upstream source and real Host/Chromium checks, without raising the supported DSH/Node floor. / 固定上游精确源码与真实 Host/Chromium 验收 `0.2.1-rc.3`，不抬高 DSH/Node 最低支持要求。
- **#745, #747, #748, #750**: Scoped HTTP 400 token-limit parsing, official route matching and trusted model-capability hints; do not infer that every vendor-specific HTTP error is fixed. / 收敛 HTTP 400 token 限额解析、官方路由匹配和模型能力提示的信任边界；不代表所有供应商 HTTP 错误均已解决。
- **#746**: Restored vendor catalog ownership to DSH while retaining the packaged Web sidecar. / 将供应商目录归属交还 DSH，保留随包发布的 Web sidecar。
- **#740**: Improved `doctor`'s safe, paste-ready GitHub issue template. / 优化 `doctor` 生成可安全粘贴的 GitHub Issue 模板。
- **#752 and #753**: Updated the lockfile to patched `follow-redirects@1.16.1` and `zod@4.6.6`, respectively. Existing GitHub advisory states may take time to reconcile; changes do not claim an independent full security audit. / 锁文件纳入修复后的 `follow-redirects@1.16.1` 与 `zod@4.6.6`。GitHub 告警状态可能延迟同步；本次升级不代表完成额外全面安全审计。
- **#758**: Patch `undici` to >=7.30.1 (staying in major 7), and `puppeteer-core` to >=25.16.0 (staying in major 25). The latter removes the vulnerable `chromium-bidi -> zod@3.24.1` production dependency; the direct Zod minimum is raised to `^4.6.6`. The **combined v3.1.0 source candidate** passed `pnpm audit --prod --audit-level high --registry https://registry.npmjs.org` with **no known vulnerabilities**. This is not a guarantee that future advisories cannot appear. / 修复 `undici` 与 `puppeteer-core` 的生产依赖漏洞，消除 Chromium BiDi 引入的旧 Zod 3，并将直接 Zod 最低版本提高至 `4.6.6`。合并预演候选在官方 npm 注册表执行生产依赖审计显示“未发现已知漏洞”；这不等于保证未来不会出现新漏洞。
- CI and dependency Action pins were refreshed where validated. / 更新已验收的 CI 与依赖 Action 固定版本。

## Compatibility and known boundaries / 支持窗口与边界

- Node `^22.19.0` or `>=24.0.0` (as stated in package metadata). DSH `>=0.1.5-rc.1 <0.2.0-0 || >=0.2.0-rc.2 <0.3.0-0`. No new Host privileges, automatic Host configuration rewrite, Session schema migration, or public API breaking change is intended.
- 继续支持上述 Node 和 DSH 版本范围；不新增 Host 权限、不擅自改写 Host 设置、不迁移 Session 格式、不故意引入公共 API 破坏性变更。
- #756 only affects **notice presentation**; it does not introduce a new consent system or alter network enforcement. A browser-only localStorage preference is not synchronized across browsers or devices. / #756 只改变**提示展示**，不新增隐私授权机制，不改变网络拦截逻辑。浏览器提示偏好不会跨设备同步。
- Historical intermittent Desktop selection/RPC issues (e.g. #738), vendor-specific HTTP reports and upstream installer behavior are not claimed resolved solely by this minor release. / 历史偶发 Desktop 选择/RPC、特定供应商 HTTP 以及上游安装器问题，不能仅因本版本发布就宣称已全部根修。

## Release evidence / 发布验收

- #754 and #756 completed their exact PR-head cross-platform CI with no failures (#754: 105 successes, 1 conditional skip; #756: 105 successes, 1 conditional skip), including Node 22/24 and real Host gates. / #754 与 #756 的精确 PR-head 跨平台 CI 均零失败，Node 22/24 与真实 Host 门禁通过。
- The final combined release-preparation commit, npm tarball, OIDC provenance and published artifact are separate gates and **must be checked before calling v3.1.0 released**. / 最终合并后的候选提交、npm 包体、OIDC 来源证明及发布结果仍需受保护流程核验，未完成前不得称正式发布。
