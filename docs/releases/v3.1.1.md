# v3.1.1 — maintenance patch / 维护修正版

These are candidate release notes. Availability is established only after the protected release workflow publishes an immutable GitHub Release and verified npm package.

本文是候选版更新说明。只有受保护发布流程完成，并核对不可变 GitHub Release、npm 包及来源证明后，才算正式发布。

## Session tool visibility and isolation / 会话工具可见性与隔离

- **#761:** After successful HMR/recomposition, retained Agents immediately regain their previous Session Vision-OFF tool mask; Vision-ON Agents stay ON. Execution-time policy remains fail-closed. / HMR 或重组后立即恢复旧 Agent 的识图关闭遮罩，不影响开启状态，不放宽执行期权限。
- **#762:** Resolve same-name tools using the actual Agent scope instead of an implicit global lookup, preserving other plugins' Agent-local tool shadows. / 按实际 Agent 作用域查询同名工具，避免误删其他插件在该 Agent 中的工具。
- **#763 and #764:** Add pinned DSH RC3 Agent-scoped visibility regressions and clarify the composer Vision switch's authority. When progressiveTools is false, vision_activate is intentionally absent. / 补充 RC3 真实工具作用域回归测试，明确会话识图开关权限；非渐进模式不注册 vision_activate。

## Image rejection recovery / 上游拒图回退

- **#769 (fixes #768):** Recognize a gateway's explicit `The request model is not multimodal` rejection and retry once through the existing canonical image-to-text bridge before output. The fix does not swallow generic HTTP 400, unsupported format/size, cancellation or Session restriction. / 识别网关明确提示模型非多模态时的拒图，输出前经原有文本桥重试一次；不误判通用 HTTP 400、图片大小或格式限制，也不绕过取消与会话权限。
- **Validation boundary:** This source fix is not a credentialed end-to-end test of the original Windows Desktop + dsh-codearts account. The dated upstream model's actual image capability still depends on the gateway. / 验收边界：尚未使用报告用户的 Windows CodeArts 账号完成真实网关端到端复测，不能保证上游模型本身支持图片。

## Cross-version source builds and DSH RC5 / 跨版本编译与 DSH RC5

- **#772 (fixes #771):** Type-only compatibility for separate Host Zod 4.4.3 and DVR Zod 4.6.x copies at the Storage Domain schema boundary, without changing runtime parser, record format or persistence. **#773** adds the pinned RC3 cross-copy compiler guard. / 修复两个 Zod 副本的静态类型不兼容，保持运行时解析与持久化语义不变；新增固定 RC3 混合 Zod 编译回归。
- **#770:** Qualify DSH 0.2.1-rc.5 exact source at b830ec950faba0a46dda564be3e2d854afed94f1, with Windows Node 22/24 Desktop, macOS/Linux, real Host + Chromium and reasoning Body Slot display behavior. / 验证 RC5 精确源码、三端真实 Host、Windows Node 22/24、浏览器以及推理内容显示逻辑。
- **#767, #765, #766:** Improve alpha Host executor acceptance and update pinned CI security actions. / 修正 Alpha Host 执行器验收并更新固定版本的 CI 安全 Action。

## Compatibility and limits / 兼容与限制

- Supported Node remains ^22.19.0 or >=24.0.0. DSH remains >=0.1.5-rc.1 <0.2.0-0 or >=0.2.0-rc.2 <0.3.0-0. No new Host privileges, Settings migration, Session format change or breaking public API. / 保持既有 Node、DSH 支持窗口，不新增 Host 权限、配置迁移、Session 格式变化或破坏性公开 API。
- **#759** was closed as not-planned due to missing distinguishing evidence from the reported Windows 34-bundle environment; this release does not claim it was fixed. Reopen if a Vision-ON Agent demonstrably cannot see its authorized tool. / #759 因原始 Windows 34-bundle 故障缺少关键判别证据而归档，不代表修复；如可确认 Vision 开启的 Agent 仍无法调用授权工具，应重新开启。
