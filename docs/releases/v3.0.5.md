# v3.0.5 release candidate

This is a corrective patch for the existing 3.0.x line, not an announcement that npm has already published it.

## Included
- #727: successful `vision_describe` guidance now uses a source-attributed `notice`, so a synthetic injected context does not terminate the assistant's visible answer. Original contribution from @kevindawn11-hash in #728 (authored commit `14c67c7`, preserved in history by merge #733), paired with Session V3/V4 source-boundary fix #731. The final merged source is `main@0fc51c3` and no npm publication is implied.
- #730: updated latest-alpha CI to accept DSH JSONL namespace plugin exports in addition to older defaults; the exact published alpha lifecycle passed on Node 22/24. This is CI-only.
- #721 qualifies DSH 0.2.1-rc.1 at upstream 1600d8a1e140dcde43a1a0941940a0480712c011 with exact source and real Host/Chromium/Settings/attachment CI.
- #722 fixes #719 by removing two unused imports of optional DSH dependencies, originally contributed by @m4ku1337 in #720. Missing optional peers must not prevent Desktop activation.
- #723 checks the actual OVHcloud VLM JSON body against its documented 10 MB limit before egress. Only the official OVH endpoint is affected; image content is not silently changed.

## Compatibility
Node ^22.19.0 or 24+. DSH >=0.1.5-rc.1 <0.2.0-0 or >=0.2.0-rc.2 <0.3.0-0. No settings or session migration, new Host privileges, or API breaking changes.

## Qualification
Each fixing PR passed its final-head CI. The candidate version still requires its own Node, packed artifact, real Host and browser verification. For detailed acceptance evidence see docs/development/v305-real-scenario-acceptance.md.

## Still open
- #684: intermittent historical Windows Node24 Vision toggle click loss; newer CI success does not prove this was fixed.
- #704: reported coexistence problem with billion-context or billion-context-dsh, not yet reproduced with exact version and logs.
- #716: user-reported backend HTTP 400, not confirmed fixed by the separate OVH payload limit preflight.
- #703: upstream installer writer-lock contention; closed as out of scope, not repaired by DVR.

Publication is a separate release gate and is not performed by this preparation PR.
